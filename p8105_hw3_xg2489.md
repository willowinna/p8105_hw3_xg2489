\##January vs July

``` r
mean_tmax = ny_noaa_df |>
  filter(month == 1 | month == 7) |>
  mutate(
    month = factor(month, levels = c(1,7), labels = c("January", "July"))
  ) |>
  group_by(id, year, month) |>
  summarise(
    mean_tmax = mean(tmax, na.rm = TRUE)
  ) |>
  view()
```
